# Módulo Integrado V1 — Registro da Sprint 4 / Semana 5

## 1. Objetivo

Integrar o MVP front-end da Sprint anterior com a identidade visual e os padrões documentados no Design System, preservando o conteúdo e o fluxo definidos no roteiro fechado.

## 2. Escopo integrado

A experiência final da V1 segue a sequência:

**Início → Entenda → Perfil dos Envolvidos → Consequências → Como Enfrentar → Atividade Interativa → Precisa de Ajuda**.

## 3. Critérios aplicados

- Identidade visual consistente em toda a interface.
- Reutilização de cores, tipografia, raios, botões, cards e espaçamentos.
- Menu principal consistente e menu mobile.
- Jogo educativo integrado à mesma linguagem visual.
- Layout responsivo.
- Acessibilidade básica.
- Ausência de coleta de dados pessoais.
- Conteúdo mantido próximo ao roteiro aprovado.

## 4. Decisões

A V1 não adiciona banco de dados, cadastro, chatbot ou denúncia real. Essas funcionalidades permanecem dependentes das etapas posteriores definidas pelo projeto e dos requisitos de privacidade, segurança e moderação.
